# UI Code Preview

Навык Codex для реконструкции, генерации, редизайна и глубокого UI/UX-ревью интерфейсов по исходному коду проекта.

Инструмент собирает отдельный интерактивный HTML-workbench без запуска приложения, эмулятора или dev-сервера. Исходный проект остаётся неизменным до отдельного подтверждения внедрения.

## Возможности

- реконструкция экранов Android, iOS, Web, React Native и Flutter;
- дерево всех экранов и переходов;
- режимы «Все макеты», «Прототип», «Один экран» и Before/After;
- инспектор элементов и комментарии с привязкой к экрану и узлу;
- детерминированные проверки геометрии, масштаба, меню, состояний, доступности и навигации;
- экспертное UI/UX-ревью с доказательствами и вариантами исправлений;
- стандарты Material, Apple HIG, WCAG и ARIA APG;
- открытие подготовленной задачи Codex через официальный `codex://new` deep link без bridge-сервера;
- строгая граница между одобрением макета и изменением исходного кода.

## Установка

Клонируйте репозиторий в каталог навыков Codex:

```powershell
git clone https://github.com/Elgreed/ui-code-preview.git "$env:USERPROFILE\.codex\skills\ui-code-preview"
```

После установки перезапустите Codex или начните новую задачу. Навык можно вызвать явно:

```text
$ui-code-preview собери интерактивный макет UI из этого проекта
```

## Основной процесс

1. Codex сканирует UI и навигацию проекта, не запуская приложение.
2. Создаёт `ui-ir.json` — переносимое представление экранов, компонентов, состояний и связей.
3. Генерирует автономный `ui-preview.html`.
4. Выполняет проверки покрытия, платформенных стандартов и взаимодействий.
5. Пользователь комментирует, выбирает проблемы и сравнивает варианты Before/After.
6. Изменения исходного проекта предлагаются только после отдельного одобрения макета.

Полный рабочий контракт находится в [SKILL.md](SKILL.md). Детальные правила и схемы — в [`references/`](references/), исполняемые проверки — в [`scripts/`](scripts/).

## Требования

- Codex с поддержкой локальных навыков;
- Python 3.10+;
- Node.js для headless smoke-проверок;
- Chrome, Edge или Chromium для снимков и геометрической диагностики.

Приложение, эмулятор, bridge-сервер и сетевой dev-сервер для построения макета не требуются.
